# Operator language pack (casual employee)

Use short next-step sentences. Avoid `AssertionError`, stack traces, and “contact an administrator” for normal mistakes.

| Situation | Say |
|-----------|-----|
| No scale | Connect the scale first (Scale → Scale Setup → Connect). |
| No live samples | Wait until the big weight number is updating, then try again. |
| Cal test fail | Measured X g vs reference Y g. Keep the same mass on the pan, wait, then press Test again. Calibration was not saved. |
| Sticky big negative | Calibration was not saved. Large numbers are still uncalibrated — finish Guided Calibration, then press ZERO. |
| Scanner test timeout | No scan received. Check cable or Bluetooth pairing, and that the scanner is in keyboard mode. |
| Auto ID | Using an automatic plant ID so you can weigh without a scanner. |
