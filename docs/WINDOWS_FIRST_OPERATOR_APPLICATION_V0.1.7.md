# Windows-First Operator Application - v0.1.7

PySide6 is the primary UI. The design system is defined in `frontend/design_tokens.v0.1.7.json` and `frontend/themes/windows_light.qss`. Windows-specific native execution remains unproven until a Windows runner builds and executes the packaged application.

Primary operator actions: Start/Resume, Connect Scale, Zero, Set Tare, Confirm & Record, Cancel, Finish Run. Advanced functions are under Run, Scale, Tools, and Help menus.
