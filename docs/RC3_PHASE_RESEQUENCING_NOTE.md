# RC3 Phase Resequencing Note

The `v0.1.4` roadmap originally pointed directly from `rc3a_llm_validation_harness_and_drift_profiles` to hardware inventory and wiring.

`v0.1.5` inserts a software-only closure phase before physical integration:

```text
rc3a — LLM validation harness and drift profiles
rc3b — Software dry run and agent bootstrap entry-point hardening
rc3c — Hardware inventory, wiring truth, and physical integration
rc3d — Firmware compile, upload, and protocol bring-up
rc3e — Physical stream, zero, and tare validation
rc3f — Calibration, repeatability, and load validation
rc3g — Physical scan/weigh/record/validate/resume
rc3h — Local control bridge and evidence closure
```

No prior phase was discarded. The planned hardware phases were shifted forward and remain `NOT_RUN` until executed.
